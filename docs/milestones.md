## M1 任务清单

**目标**：完成可以洗牌、发牌、构造合法 GameState 的基础设施。**不做**听牌、役、点数、状态转移。

1. `tiles.py`
   - Tile 编码（0-33）、字符串解析（`"1m"` / `"赤5m"` / `"东"`）、显示
   - 派生判定函数（`is_manzu` / `is_yaochuuhai` / ...）
2. `hand.py`
   - `Hand` 容器（counts + 赤五标志 + 副露）
   - 添加/移除牌、序列化、合法性断言
3. `wall.py`
   - 牌山构造（按 mode 分；M1 只实现 yonma，留 `mode` 参数）
   - 王牌区、宝牌指示牌翻开
   - 赤五注入位置（按 `docs/rules.md` 第 2 节）
4. `rng.py`
   - 种子化随机洗牌（必须可种子化，用于复现 bug）
5. `game_state.py`
   - 不可变 `GameState`（frozen dataclass）
   - 字段：场风 / 局 / 本场 / 积棒 / 四家手牌 / 四家河 / 副露 / 宝牌指示 / 巡目 / 当前 active player
6. 单元测试覆盖以上所有（`engine/tests/`）
7. 文档：`docs/tile-encoding.md` 已就绪；`docs/rules.md` 在 M1 启动前必须填到能定义"赤五数量与注入位置 / 牌山长度 / 王牌区构造"

**M1 验收**：

- `uv run pytest` 全绿
- 能用种子复现完整初始局面
- `hypothesis` 属性测试覆盖：任意 counts 数组互转字符串、洗牌后牌山长度恒定且元素不重不漏
